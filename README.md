# Encrypted research reader

This public repository exists only to serve the password-encrypted research page at https://vjk7989.github.io/gan-kanjcj-pages/.

Its `index.html` is a StatiCrypt ciphertext build. The research source repository remains private. This deployment repository does not contain the password, plaintext report, source downloads, company PDF, or build inputs. Downloads are generated in the browser after unlocking.

Browser-side encryption is a reading gate, not server-side access control. Public ciphertext permits offline password guessing, and anyone with the password can save the decrypted page. The build disables StatiCrypt's remember option.
